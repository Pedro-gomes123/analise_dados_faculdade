2. Metodologia: Coleta e Processamento (ETL)

Os dados foram obtidos por meio da API de agregados do IBGE (versão 3), consultando a tabela 4093 da PNAD Contínua Trimestral, variável 4099 (taxa de desocupação das pessoas de 14 anos ou mais de idade), com recorte territorial para o estado de Pernambuco e classificação por sexo (total, homens e mulheres). A requisição foi feita em Python, com leitura direta do JSON retornado pela API por meio da biblioteca pandas, o que garante reprodutibilidade e acesso a dados sempre atualizados na fonte oficial.

Na etapa de extração, o JSON hierárquico retornado pela API foi percorrido para isolar as três séries temporais (total, homens e mulheres), que foram convertidas em DataFrames individuais e depois consolidadas em uma única base estruturada, com as colunas período, valor e sexo. Essa consolidação permite tratar as três séries de forma unificada nas análises comparativas.

No tratamento e limpeza, identificou-se que a API retorna a string "..." para períodos sem dado divulgado (trimestres futuros ou ainda não apurados). Esses valores foram substituídos por 0 e a coluna de valores foi convertida para o tipo numérico (float), viabilizando os cálculos estatísticos; nas etapas de análise, os registros com valor 0 foram explicitamente excluídos, para que os marcadores de ausência não distorcessem as medidas. Por fim, na padronização, o campo de período (no formato AAAATT, ex.: 202301) foi decomposto em duas variáveis: ano e trimestre, o que possibilitou a agregação anual das taxas pela média dos quatro trimestres de cada ano.
